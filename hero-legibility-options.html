Hero legibility

Readable Without A Shadow

No shadow can fix this, and it is worth being precise about why: parts of the card screenshots are brighter than the cream text itself. A shadow outlines a letter, it cannot darken what sits behind it. So every real answer below changes where the text and the cards are, not what is painted between them.

AA asks 3.0:1 for text this large. Cream is comfortable on any navy in the palette and hopeless on anything pale, which is exactly the split the carousel puts underneath it.

A, split
Option A

Stop Them Overlapping, Split The Hero

Copy in a column on the left over plain navy, carousel to the right. The text never crosses a screenshot, so it reads at 12.73:1 with no shadow, no scrim and the cards at full brightness. It also gives the headline a left edge to align to, which large display type generally prefers.

The cost is that it is a different hero. The centred, symmetrical composition goes, and the cards get roughly half the width, so fewer are visible at once.

Biggest change, best result

B, corridor
Option B

Open A Corridor Through The Carousel

Keep the centred composition exactly as it is, but leave one slot empty as it passes the middle, so there is always a navy gap directly behind the words. Cards either side stay at full brightness and keep moving. The text sits on navy, so again 12.73:1 with nothing painted over anything.

This is my recommendation: it is the only option that keeps the hero looking the way you have tuned it. The work is in js/reels.js, which currently spaces cards evenly, so it needs to carry a deliberate blank at one position.

C, text above
Option C

Put The Copy Above The Cards

Shrink the cards and push them down so they rise from the bottom edge, with the copy in clear navy above. You can try this right now with the two controls already in #tune: Card size and Text up / down. At card size 40% and text -150px the eyebrow and the first line already clear the cards.

The cost is that the samples get smaller, which runs against the earlier note about making them bigger so they are not blurry. Worth testing before committing to anything else, because it costs nothing to try.

D, all cards dimmed
Option D

Dim Every Card Equally

One line on the iframes, and because the dimming is uniform there is no edge anywhere, which is the thing you have been pointing at. But the numbers are unkind: a white screenshot has to come down to 50% brightness before cream text reaches even 3.36:1, and that is as dark as the mock above.

I would not do this. It makes every design look muddy, which is the opposite of what the samples are there to prove, and you have twice asked for the templates to look clear. Listed because it does technically solve the problem.

Now, ellipse scrim
For reference

What Is Live Today

The ellipse scrim, softened. It works, and the edge is fainter than it was, but it is still a darkened region laid over the cards and its boundary is still findable, which is the thing that started this.

One more idea that is not on this list because it is still a shadow in disguise: a dark outline on the letters via text-stroke. It is crisper than a blur, but it is the same family of fix and it changes how the serif reads at 96px, which on Fraunces is a real loss.
