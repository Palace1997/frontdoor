Five Bento Layouts For Everything Included

Same nine features, same copy, five different grids and five different icon treatments. Each one is shown at full width with the real fonts and the real section colours, so what you see is what the section would look like. Nothing is changed on the site yet, tell me a number.

Icons: filled green rounded chip, white glyph, soft shadow. The closest to what is there now, but the flat 3x3 becomes a proper bento with one large anchor tile. Safest option, reads as a modern product page.

Worth knowing before you pick

  • The icons are one set, drawn once. All five options use the same nine monoline glyphs, so the choice is only about how they are presented: filled chip, bare line, outlined circle, white circle on tint, or small green line with a numeral. Picking a layout and an icon treatment from different options is fine, say so and I will mix them.
  • The copy is slightly shortened in a few of the smaller tiles so they sit evenly. Say the word if you would rather keep the current wording exactly and let the tiles run to different heights.
  • All five keep the existing staggered entrance and collapse to two columns on tablet and one on phone.
